# Banquo In-App Microcopy Reference

Quick-reference voice guide for button labels, empty states, tooltips, error messages, confirmation copy, and GhostLight's own lines. Full standards live in the "Banquo | Copywriter" project — this is the trimmed version so implementation prompts stay code-focused while microcopy stays on-voice.

## The core rule
Concrete over smooth. Say what the thing does or what happened, in plain terms, using Banquo's actual nouns (scene, cue sheet, call sheet, department, GhostLight) — not generic SaaS abstractions (workflow, solution, seamless experience).

## Banned words in UI copy
seamless, leverage, dynamic, robust, streamline, empower, unlock, elevate, cutting-edge, effortless, powerful, intuitive, "in today's fast-paced world," "all-in-one."

## Quick patterns

**Empty states** — say what's missing and what to do, don't sell it:
- ❌ "Unlock powerful scene insights by getting started today!"
- ✅ "No scenes yet. Add one to start tracking props, cues, and costumes."

**Errors** — say what happened and, if possible, what to do next. No apology theater:
- ❌ "Oops! Something went wrong on our end. We're on it!"
- ✅ "Couldn't save this cue. Check your connection and try again."

**Confirmations / success** — plain statement of fact, not a celebration:
- ❌ "Amazing! Your import was a total success!"
- ✅ "12 props imported. 2 skipped — missing scene assignment."

**Button labels** — verb + object, no adjectives:
- ❌ "Get Started Now"
- ✅ "Add Scene" / "Import Props" / "Save Cue"

**Tooltips** — one clause, mechanical, not persuasive:
- ❌ "This powerful feature helps you manage your workflow effortlessly."
- ✅ "Pulls props and costume needs from every scene in this act."

**GhostLight's voice** — knows the production, speaks plainly, dry rather than chipper. Not a hype-man, not a customer-service bot. Think stage manager who's seen every version of this problem before, not a mascot.
- ❌ "Hi there! I'm GhostLight, your AI theatre buddy! Let's make some magic! ✨"
- ✅ "Three scenes still need a lighting cue before tech week."

## Theatre terms — use exactly, don't soften
call sheet, cue sheet, strike, tech week, dress (rehearsal), blocking, department, act/scene. Don't generalize these into business-speak for a "broader audience" — precision is a trust signal to the people actually using this.

## When in doubt
Ask: would this line survive if it were on a competitor's generic project-management tool with the name swapped? If yes, it's not specific enough yet — reference the scene/production/department data directly instead of describing a benefit in the abstract.

For anything bigger than a UI string — a marketing page, an email, a press blurb — route it to the "Banquo | Copywriter" project instead of drafting it here.
